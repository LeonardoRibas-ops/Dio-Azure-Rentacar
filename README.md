# 🚗 RentACar Cloud-Native – Powered by Azure ☁️

Seja bem-vindo ao **RentACar**, um projeto desenvolvido com o objetivo de demonstrar uma arquitetura moderna, totalmente Cloud-Native, escalável e gerenciada através do poderoso ecossistema do **Microsoft Azure**.

---

## 🔥 O que é isso?

Imagine que você precisa construir um sistema de **aluguel de carros**, com:

- Interface web (frontend)
- API intermediária (BFF)
- Processamento assíncrono com filas
- Microsserviços com Azure Functions
- Infraestrutura como código com Bicep
- CI/CD com GitHub Actions

Este projeto cobre **TUDO isso**. Legal, né?
